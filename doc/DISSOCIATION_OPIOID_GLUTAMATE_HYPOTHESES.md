# Dissociative-State Stability: Opioid / NOP / Glutamate Research Hypotheses

> Research hypothesis document. **Not a clinical protocol and not a treatment
> recommendation.**
>
> There are no established pharmacological treatments for DID identity-state
> switching itself. The purpose of this document is to turn unusual longitudinal
> observations and existing dissociation pharmacology into falsifiable questions.

## Core observation to explain

A hypothesis-generating longitudinal observation suggested a pattern in which
methamphetamine exposure was associated with:

- sharply increased involuntary switching;
- reduced voluntary control over switching;
- more concurrently/recurrently active self-states;
- previously inhibited states gaining executive control more easily;
- increased conflict between state-specific interests;
- collapse of an established daily internal coordination routine;
- subsequent withholding and deliberate deception between states.

An important detail is that the coordination routine occurred **on waking**. The
hypothesis is therefore not simply "sleep deprivation worsens dissociation." Irregular
or absent normal waking events may have removed a repeated synchronization point used
to reconcile memory, plans and state-specific information.

This observation is anecdotal and cannot establish mechanism. It is useful because it
generates measurable endpoints.

## Working systems model

```text
                 stress / salience / catecholamines
                              |
                              v
                    executive-state gating
                    /         |          \
                   /          |           \
              opioid         NOP       glutamate/NMDA
           MOR/KOR/DOR                 HCN1 / cortical E-I
                   \          |           /
                    \         |          /
                     thalamocortical integration
                              |
                              v
                  state persistence / switching
                              |
                 +------------+------------+
                 |                         |
          memory permeability       internal coordination
```

The model deliberately separates **sedation** from **stabilization**.

A drug that merely suppresses speech or activity is not considered successful.

## H1 — KOR/dynorphin signaling is pro-dissociative

Controlled human exposure to the selective KOR agonist enadoline produced
depersonalization, visual distortions and psychotomimetic effects.

Prediction:

```text
greater KOR agonist signaling
    -> greater detachment / dysphoria / perceptual disconnection
```

Therefore KOR antagonism/inverse agonism deserves direct investigation as a potential
stabilizing axis.

Reference:
https://pubmed.ncbi.nlm.nih.gov/11594439/

## H2 — high-affinity low-efficacy MOR signaling may behave differently from full agonism

The useful question is not "opioid agonist or antagonist?"

A high-affinity partial agonist can theoretically reduce variance in receptor output:
it provides activity when endogenous tone is low while constraining signaling relative
to a high-efficacy agonist when tone is high.

Buprenorphine is a useful **pharmacological architecture**, not evidence for a DID
treatment: high-affinity MOR partial agonism with KOR antagonism/inverse agonism and
additional NOP activity.

References:
https://pubmed.ncbi.nlm.nih.gov/31994020/
https://pubmed.ncbi.nlm.nih.gov/35999975/

Prediction:

```text
MOR partial agonism + KOR antagonism
    may alter state stability differently from
full MOR agonism or blanket opioid antagonism
```

This must be tested rather than inferred.

## H3 — endogenous opioid dysregulation contributes to dissociation

A systematic review/meta-analysis reported a signal for opioid antagonists reducing
dissociative symptoms:

- five comparative studies;
- 154 total participants;
- pooled effect size d = 1.46;
- high heterogeneity and probable publication bias.

This is weak-to-moderate hypothesis support, not definitive treatment evidence.

Reference:
https://pubmed.ncbi.nlm.nih.gov/37860852/

The research question should include receptor selectivity. A non-selective antagonist
result does not identify MOR, KOR, DOR or NOP as the causal subsystem.

## H4 — NOP/ORL-1 modifies switching threshold and state persistence

NOP participates in stress, reward, memory and opioid system regulation. The legacy
corpus contains selective agonists and antagonists, making this a useful computational
comparison axis.

Do not assume direction.

Prediction:

```text
NOP perturbation
    -> measurable change in switching threshold,
       persistence, coordination, or reward/salience response
```

## H5 — NMDA-dependent cortical integration is a core state-gating mechanism

Ketamine provides a causal pharmacological model of dissociation. Current review work
links its dissociative effects to NMDA receptor antagonism, HCN1 effects, pyramidal-cell
disinhibition and altered thalamocortical connectivity.

Reference:
https://pubmed.ncbi.nlm.nih.gov/41453872/

Therefore the useful target is **normalization of glutamatergic integration**, not
generic NMDA antagonism.

Prediction:

```text
destabilized cortical E/I + thalamocortical integration
    -> lower state-transition threshold
    -> reduced executive-state persistence
    -> increased blending / involuntary switching
```

## H6 — catecholamines are modulators rather than the whole mechanism

Methamphetamine perturbs dopamine and norepinephrine strongly, but a purely dopaminergic
model does not explain the full observed architecture.

A useful model is:

```text
methamphetamine
    -> catecholaminergic salience / disinhibition
    -> lower gating stability
    -> more state competition

plus

methamphetamine
    -> disrupted wake-time routine
    -> missed information-synchronization event
    -> divergent state knowledge / goals
    -> conflict and deception
```

These pathways can coexist.

## Required endpoints

A useful DID/dissociation study must measure system behavior, not just a total symptom
score.

### Primary

```text
S = involuntary switches / 24 h
P = mean executive-state persistence time
C = cross-state information consistency
M = cross-state memory transfer / accessibility
R = internal coordination events completed / expected
D = detected inter-state deception or deliberate withholding events
```

### Secondary

- number of distinct states observed per day;
- co-conscious / blended-state events;
- patient-versus-observer agreement;
- state-specific autonomic clusters (HR/HRV/EDA);
- state-specific EEG feature clusters when available;
- wake-time regularity;
- coordination-meeting completion;
- affective state;
- psychotic symptoms measured separately from dissociation;
- cognition/sedation to detect false "improvement" caused by suppression.

A candidate stabilizer should ideally produce:

```text
S down
P up
C up
M up or becomes more voluntarily accessible
R up
D down
```

without major cognitive suppression.

## Observation architecture

Retrospective self-report alone is structurally weak when amnesia is itself an endpoint.

Use three independent channels:

```text
patient self-report
        +
live-in / romantic partner or other continuous observer
        +
objective telemetry
```

The observer records before comparing notes with the participant:

- observed state / unknown;
- confidence of identification;
- switch observed;
- apparently voluntary vs involuntary;
- blend/co-presence suspected;
- memory discontinuity noticed;
- coordination meeting completed;
- information withholding/deception reported or independently detected;
- relevant exposure/event timestamps.

Telemetry can contribute:

- sleep/wake timing;
- activity;
- HR/HRV;
- optional EDA;
- optional ambulatory EEG.

## Methamphetamine study design

Do **not** administer methamphetamine experimentally for this question.

Use a naturalistic case-crossover design in participants who already have independently
diagnosed dissociative pathology and independently occurring stimulant exposure.

Compare the same individual across:

```text
stable baseline
-> pre-exposure
-> naturally occurring exposure
-> acute recovery
-> return to baseline
```

Model the wake-time coordination event separately from total hours slept.

A key test is whether:

```text
meth exposure -> missed coordination event
missed coordination event -> later switching/conflict
```

remains significant after accounting for sleep duration and general arousal.

assigned.

## Falsification criteria

The model should be weakened or rejected if, under controlled observation:

1. switching/state persistence changes track sedation but not receptor mechanism;
2. KOR manipulation does not alter dissociative endpoints despite adequate target
   engagement;
3. NMDA/glutamate measures do not correlate with state-transition behavior;
4. observer-derived switching endpoints fail to agree above chance with independent
   physiological clusters;
5. the wake-time coordination hypothesis explains no additional variance beyond total
   sleep disruption;
6. purported state-specific physiological signatures fail blinded replication.

The aim is not to prove a favored DID model. The aim is to build experiments that can
kill it.
